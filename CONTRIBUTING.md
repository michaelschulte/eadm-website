# Adding files and newsletters

PDFs, including newsletter issues, live in a separate repository,
<https://github.com/michaelschulte/eadm-website-files>, which this site
includes as its `files/` folder. Writers get push access to that
repository only. Its
[CONTRIBUTING.md](https://github.com/michaelschulte/eadm-website-files/blob/main/CONTRIBUTING.md)
explains how to upload a file or a newsletter.
